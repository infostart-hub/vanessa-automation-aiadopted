# Сборка Vanessa Automation из исходников на macOS

Инструкция описывает локальную сборку поставки Vanessa Automation из исходников установленной платформой 1С на macOS для запуска воспроизводимых сценарных проверок через `vanessa-runner`.

Используются OneScript 2.2.1 и локальные зависимости в `oscript_modules`. Файл `tools/onescript/oscript.cfg` подключает этот каталог к сборочным скриптам; каталог зависимостей и собранные бинарные артефакты не отслеживаются в Git.

После установки зависимостей выполняются `tools/onescript/ZipTemplates.os` и `tools/onescript/Compile.os`. Для рабочей поставки одной главной `vanessa-automation.epf` недостаточно: при старте используются вспомогательные обработки `locales/Steps.epf`, `lib/Video/РаботаСВидео.epf`, `lib/FeatureReader/vbFeatureReader.epf` и макет `TestClients` для штатного управления клиентами тестирования, после чего подключаются каталоги библиотек шагов. Отсутствие вспомогательной обработки диагностируется по журналу регистрации 1С (в том числе по стартовым отметкам `VanessaAutomation.Startup`, позволяющим отделить загрузку форм, библиотек и настроек от ошибок прикладной конфигурации).

Проверка собранной поставки подтверждается реальным запуском проходящего и падающего сценариев через `vanessa-runner`, выгрузкой отчётов JUnit/Allure и штатным завершением всех собственных процессов группы.
